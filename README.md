# Astra Visuals

Сайт клиентского мода **Astra Visuals** для Minecraft 1.21.11, 1.21.1 и 1.16.5 (Fabric)
и страница того, что в моде менялось.

- **Сайт:** https://pythonaby-code.github.io/astra-visuals/
- **Что нового:** https://pythonaby-code.github.io/astra-visuals/changes/
- **Скачать мод:** [`astravisuals-1.0.0.jar`](astravisuals-1.0.0.jar) — файл, на который
  ведёт кнопка на сайте. Рядом лежат сборки по версиям игры:
  `astravisuals-1.21.11.jar`, `astravisuals-1.21.1.jar`, `astravisuals-1.16.5.jar`.
  Fabric API не нужен ни одной из них.

## Что внутри мода

Свой главный экран с часами и обоями, жидкое стекло во всех окнах, плашки HUD с
перетаскиванием, предупреждения («зелье вот-вот закончится», «броня вот-вот
сломается», «здоровье на исходе»), метки по координатам из чата (`.gps 845 72 2338`),
полоски здоровья над существами и счёт боя. Бой: круг досягаемости, кольцо под целью,
тотемы, серия ударов, подпись стрелы. Косметика настоящими текселями, свечение
персонажей, следы и пыль, свой список игроков на Tab и свой экран клавиш.
Двенадцать разделов настроек под правым Shift, 185 настроек, восемь тем, четыре шрифта.

Все кадры на сайте сняты в самой игре.

## Сайт 2.0 (3 октября 2026)

С релиза 2.0 главная — это `index.html`, `features.html`, `download.html`, `profile.html` и папка `v2/`
(стили, эффекты, кадры). Их исходники — `src/v2site/` (`pages/*.html` + `parts.py`), собирает
`python src/v2site/build.py` в папке нового сайта. Страница `changes/` и старые `assets/` остались от 1.0.

## Как устроен репозиторий

| Где | Что |
|---|---|
| `src/` | Исходники страниц. Они написаны под артефакт claude.ai, который сам добавляет обвязку документа. |
| `index.html`, `changes/` | Готовые страницы для GitHub Pages — **их собирает скрипт, руками не править.** |
| `assets/` | Кадры из игры, обои и знак. |
| `tools/` | Скрипт сборки и служебные утилиты (подбор шрифта, отрисовка знака). |

Пересобрать страницы после правки `src/`:

```
python tools/build_site.py
```

Шаг нужен ровно из-за одного: браузеру обязателен `<meta charset="utf-8">`, иначе
русский текст рассыпается, а артефакт такую обвязку добавляет сам.
