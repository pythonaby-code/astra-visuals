# Astra Visuals

Сайт клиентского мода **Astra Visuals** для Minecraft 1.21.11 (Fabric) и страница
того, что в моде менялось.

- **Сайт:** https://pythonaby-code.github.io/astra-visuals/
- **Что нового:** https://pythonaby-code.github.io/astra-visuals/changes/
- **Скачать мод:** [`astravisuals-1.0.0.jar`](astravisuals-1.0.0.jar) — 247 КБ, один файл,
  Fabric API не нужен.

## Что внутри мода

Свой главный экран с часами и обоями, жидкое стекло во всех окнах, плашки HUD с
перетаскиванием, предупреждения («зелье вот-вот закончится», «броня вот-вот
сломается», «здоровье на исходе»), метки по координатам из чата (`.gps 845 72 2338`),
полоски здоровья над существами и счёт боя. Десять разделов настроек под правым Shift,
четыре темы, четыре шрифта.

Все кадры на сайте сняты в самой игре.

## Как устроен репозиторий

| Где | Что |
|---|---|
| `src/` | Исходники страниц. Они написаны под артефакт claude.ai, который сам добавляет обвязку документа. |
| `index.html`, `changes/` | Готовые страницы для GitHub Pages — **их собирает скрипт, руками не править.** |
| `assets/` | Кадры из игры, обои и знак. |
| `tools/` | Скрипт сборки и служебные утилиты (подбор шрифта, отрисовка знака). |

Пересобрать страницы после правки `src/`:

```
python tools/build_site.py
```

Шаг нужен ровно из-за одного: браузеру обязателен `<meta charset="utf-8">`, иначе
русский текст рассыпается, а артефакт такую обвязку добавляет сам.

## Шрифты

Unbounded, Manrope и JetBrains Mono подключаются с Google Fonts. Шрифты внутри самого
мода — Arimo и Noto Sans Mono, оба под SIL Open Font License.
